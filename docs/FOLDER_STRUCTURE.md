## How it is checked without a local Flutter SDK

```bash
python3 tools/verify_project.py          # 17 checks, no Dart needed
cd app && flutter analyze && flutter test && flutter build apk --debug   # with the SDK
```

`verify_project.py` validates: pubspec dependencies/assets, Dart bracket and tab
cleanliness, dead imports, provider wiring, the string table and its keys,
`l10n.<x>` usage, demo JSON integrity, the sample PDF structure, PNG dimensions,
the Android runner (namespace/applicationId/MainActivity, permissions, themes,
launcher icons), the admin panel (DOM ids, pinned SDK), `node --check` on JS,
Firebase rules tokens, README links and test coverage.
