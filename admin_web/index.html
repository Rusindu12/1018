1 · Connect your Firebase project

Everything is free (Spark plan). Create a project at console.firebase.google.com, add a Web app, then paste the config object it shows you below. It is stored in this browser only (localStorage) — never sent anywhere else. See docs/ADMIN_PANEL.md for the full walkthrough.

2 · Admin sign-in

Create this user once in Firebase Console → Authentication → Users → Add user (email + password), then give it the admin claim — see docs/ADMIN_PANEL.md. Without the claim, writes are rejected by the security rules, so a leaked password alone cannot damage the catalogue.
